Leonida Platinum — an offline GTA VI trophy guide & tracker: all 55 official PlayStation 5 trophies with a saved checklist, export/import, kind and grade filters, a spoiler setting that hides story trophies until earned, a 6-stage roadmap to the platinum, 7 flagged missables, and a cited guide in its own words for every trophy.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
